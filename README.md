# 🛡️ ResQ - Інтелектуальна система розподілу гуманітарної допомоги та ресурсів

> Дипломний проєкт / Веб-застосунок для оптимізації логістики, моніторингу залишків та автоматичного розподілу ресурсів між хабами та отримувачами на основі алгоритму **Weighted Max-Min Fairness**.

---

## 📌 Про проєкт
**ResQ** розроблений для автоматизації процесів прийняття рішень у сфері гуманітарної логістики. Система дозволяє волонтерам і лікарням подавати запити на необхідні ресурси із зазначенням пріоритетів і термінів, а адміністраторам (логістам) - аналізувати поточні запаси на складах, контролювати дефіцит та автоматично формувати оптимальний план розподілу за допомогою математичного моделювання.

---

## 🚀 Що зроблено (Головний функціонал)
* **Розрахунок пріоритетів:** Автоматичне обчислення пріоритетності заявок залежно від цільового призначення, терміновості та локації.
* **Алгоритм оптимізації:** Реалізація розподілу обмежених ресурсів за принципом *Weighted Max-Min Fairness*.
* **Інтерактивна аналітика (Дашборд):** 
  * Візуалізація залишків на складах із підсвічуванням критичних дефіцитів (0 одиниць).
  * Аналітичний зріз операцій розподілу за допомогою комбінованих графіків.
* **Консолідація поставок:** Інструменти для об'єднання розбитих на кілька складів заявок в єдині логістичні ланцюжки з можливістю інтерактивного фокусування.
* **Експорт звітів:** Генерація та вивантаження повних звітів і планів розподілу у форматі `.xlsx` (Excel).
* **Ролі та безпека:** Розподіл прав доступу між неавторизованими користувачами, волонтерами (отримувачами) та адміністраторами (логістами).

## 🛠️ Технологічний стек

### Backend (Серверна частина)
* **Python** / **Django** / **Django REST Framework (DRF)** — побудова RESTful API та бізнес-логіки.
* **PostgreSQL** — реляційна база даних .

### Frontend (Клієнтська частина)
* **React.js** (Functional Components, Hooks) — побудова інтерфейсу користувача.
* **Tailwind CSS** — сучасне стилізування та адаптивний дизайн.
* **Recharts** — побудова інтерактивних аналітичних графіків та діаграм.
* **Lucide React** — набір векторних іконок.
* **SheetJS (`xlsx`)** — експорт даних у таблиці Excel на клієнті.

## ⚙️ Як запустити проєкт локально

### 1. Клонування репозиторію
```bash
git clone [https://github.com/](https://github.com/) твій-логін / resq-project.git
cd resq-project
```

### 2. Запуск Backend
Bash
# Перехід у папку з бекендом та активація віртуального середовища
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

# Встановлення залежностей
```bash
pip install -r requirements.txt
```

# Запуск міграцій та сервера
```bash
python manage.py migrate
python manage.py runserver
```

### 3. Запуск Frontend
# Відкрити новий термінал і перейти в папку клієнта
```bash
cd frontend
```
# Встановлення залежностей та запуск
```bash
npm install
npm start
```
